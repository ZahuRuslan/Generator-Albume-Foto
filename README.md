
# Generator de albume foto

Proiect individual pentru **săptămâna 9** – Generator de albume cu fotografii.

## Tehnologii
HTML, CSS, JavaScript și GitHub Pages. Nu necesită PHP sau bază de date.

## Funcționalități
- Creează albume cu titlu personalizat și 1–10 fotografii.
- Afișează fotografiile într-o galerie modernă.
- Mărește fotografiile la apăsare.
- Șterge albumele.
- Salvează datele local în browser, folosind localStorage.

## Rulare
Deschide `index.html` în browser sau publică proiectul prin **GitHub → Settings → Pages → Deploy from a branch → main → /(root)**.

**Notă:** Fotografiile nu sunt încărcate pe un server și nu sunt comune între dispozitive. Stocarea locală are spațiu limitat; pentru multe fotografii ar fi nevoie de o bază de date sau de alt sistem de stocare.
