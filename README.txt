# Generator de Albume Foto

## Descrierea proiectului
Generator de Albume Foto este o aplicație web realizată în PHP, HTML și CSS, care permite utilizatorilor să creeze și să gestioneze albume cu fotografii.
Proiectul a fost realizat în cadrul studiului individual, la tema **„Generator de albume cu fotografii”**, săptămâna 9.

## Funcționalități
- Crearea albumelor cu denumiri personalizate.
- Încărcarea mai multor fotografii într-un album.
- Afișarea fotografiilor într-o galerie.
- Vizualizarea albumelor create.
- Ștergerea albumelor și a fotografiilor acestora.
- Păstrarea fotografiilor pe server după reîncărcarea paginii.

## Tehnologii utilizate
- **PHP** – prelucrarea datelor și gestionarea albumelor.
- **HTML** – structura paginii web.
- **CSS** – designul și aspectul vizual.
- **XAMPP** – rularea aplicației pe un server local.
- **Git și GitHub** – gestionarea versiunilor și publicarea codului.

## Instalare și utilizare
1. Descărcați proiectul de pe GitHub.
2. Extrageți arhiva în folderul `htdocs` din XAMPP.
3. Porniți serverul Apache din XAMPP.
4. Deschideți browserul și accesați:

   `http://localhost:8000/index.php`

5. Introduceți numele albumului.
6. Selectați fotografiile dorite.
7. Apăsați butonul de creare a albumului.
8. Vizualizați sau ștergeți albumele create.

## Scopul proiectului
Scopul proiectului este dezvoltarea unei aplicații web simple pentru organizarea fotografiilor în albume digitale și aplicarea cunoștințelor de programare PHP, HTML și CSS.
